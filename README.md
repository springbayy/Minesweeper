# Minesweeper

A Minesweeper game written in Python using tkinter.

Originally created in **2020** as a university programming project, and
uploaded to GitHub in **2026** for archival / safekeeping.

## Run

```
python Minesweeper.py
```

Requires Python 3 with tkinter (included with the standard CPython installer).

## Contents

- `Minesweeper.py` — the game
- `images/` — tile / mine / flag image assets (`*.png`, `mina.jfif`)
- `docs/Spec.pdf` — the original assignment specification
- `topplista` — high-score list (written at runtime)
